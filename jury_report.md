# Демонстрация для жюри — «Аким на 5 часов»

**Пять решений игрока:** транспорт 25, озеленение 15, соцсфера 25, безопасность 15, городские сервисы 20 условных единиц. Это лимиты по направлениям из бюджета 100. Движок выбрал пять допустимых мер: M2 «Умные светофоры» (город), M4 «Парк / сквер» (Нура), M8 «Центр семейного здоровья» (Нура), M10 «Освещение и камеры» (Нура), M14 «Аварийные бригады ЖКХ» (город). Фактическая стоимость — **85**; 15 единиц остались свободны, поскольку каталог не позволяет купить более сильный набор в заданных лимитах.

**Astana Quality of Life Score: 56.015/100** против базы **52.558** (прирост 3.457). Общий оптимум пяти мер при бюджете 100 — **57.237** за 98 единиц. Если игрок меняет лимиты на транспорт 52, озеленение 0, соцсферу 30, безопасность 0, сервисы 16, подбор достигает глобального максимума. Все варианты оцениваются **одной формулой** на данных пяти районов и десяти показателей; число голосом агента не меняется.

**Как объясняет система:** аналитик показывает состав балла, слабый район и неиспользованные лимиты; городской эксперт указывает на транспорт, отопление и сезонные нагрузки; социальный агент помечает риск-индексы как модельные прокси и рисует вымышленные реакции жителей; главный советник сводит выводы в доклад. По выбору запускается OpenAI со структурированным JSON, без ключа работает тот же сценарий с детерминированными пояснениями. Неподтверждённые числа в текстах отмечаются проверкой источников.

**Показ на одном компьютере:**

```bash
python -m pip install -r requirements.txt
python main.py --input example_allocation.json --offline --no-color
python main.py --input example_allocation.json --offline --json
python -m akim_sim --optimize
```

Для интеграции в интерфейс: `python -m akim_sim --serve`, затем `POST /score` или `POST /simulate`. Готовые вход и полный результат: [`example_allocation.json`](example_allocation.json), [`example_report.json`](example_report.json). Исходные расходы, эффекты и жалобы — игровые данные. Индексы риска не являются вероятностями; реальные данные соцсетей и открытый API города не подключены.
